## 当前结论

- **SFT：尚未找到稳定优于 Base 的方案。** 多项去噪损失和代码恢复指标改善，没有转成可靠的完整程序正确率收益。
- **ReMDM：固定5%回改在新512题上复核为正。** 原采样33.50%→回改37.60%，提升4.10个百分点，按题配对95%区间[+2.44,+5.76]；两种子都提高，前向次数相同、生成耗时约增加7.3%。这是Base采样收益，不是SFT收益。
- **512题确认实验已完成，无追加实验。** 完整对照与数据隔离边界见下方ReMDM报告；已使用的确认集不能再作为未查看数据调参。
