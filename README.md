# MDLM 数学题生成可执行 Python：公开研究摘要

本仓库用于让网页端 AI 和读者了解实验，提供汇总、关键证据和采样方法代码。它是独立整理的公开资料，不是完整训练恢复包。

**优先阅读：[AI_CONTEXT.zh-CN.md](AI_CONTEXT.zh-CN.md)**。该文件独立覆盖任务、训练设置、各轮结果、证据边界和待讨论问题，无需遍历整个仓库。

也可直接提供 [Raw 纯文本链接](https://raw.githubusercontent.com/caijingtong22-beep/mdllm_public/main/AI_CONTEXT.zh-CN.md)，或下载该文件上传到支持附件的 AI 对话。

## 当前结论

- **SFT：尚未找到稳定优于 Base 的方案。** 多项去噪损失和代码恢复指标改善，没有转成可靠的完整程序正确率收益。
- **ReMDM：Base 权重不变，仅改变采样，出现值得复核的收益。** 开发集平均37.50%→40.49%；另128题确认集28.91%→30.47%，后者95%配对区间仍跨0。
- **新的512题固定参数确认实验：整理时仍在运行，本仓库暂不报告其部分成绩。** 此处状态是发布快照，不是实时监控。
